# PWA įdiegimas iPhone

1. „Safari“ atidarykite pateiktą saugų `https://...run.app` adresą.
2. Paspauskite **Share / Bendrinti**.
3. Pasirinkite **Add to Home Screen / Įtraukti į pradžios ekraną**.
4. Palikite įjungtą **Open as Web App / Atidaryti kaip žiniatinklio programą**.
5. Paspauskite **Add / Įtraukti**.
6. Atidarykite **Pristatymai** iš naujos telefono piktogramos.
7. Pirmą kartą eikite į **Nustatymai**, įklijuokite vienkartinį įrenginio raktą ir paspauskite **Prijungti Gateway**.
8. Patikrinkite Excel kelią: el. pašto priedą išsaugokite į „Files“, aplikacijoje spauskite **Importuoti Excel** ir pasirinkite `.xlsx` failą.
9. Pristatymo kortelėje paspauskite navigaciją ir patikrinkite, kad atsidaro „Waze“ (arba „Apple Maps“).
10. Uždarykite aplikaciją, pašalinkite ją iš App Switcher ir vėl atidarykite. Aktyvus maršrutas turi išlikti.

Jeigu naujos versijos juosta rodo **Yra nauja aplikacijos versija**, užbaikite einamą veiksmą ir spauskite **Atnaujinti**.
